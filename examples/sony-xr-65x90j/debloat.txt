# Sony BRAVIA XR-65X90J (2021, device BRAVIA_VH2, MediaTek), Google TV / Android 12 (SDK 31),
# firmware BRAVIA_VH2_UC-user 12 STT2.230505.001.S136 682241 (US). 3 GB RAM, 4 GB /data. ro.adb.secure=1.
# Same platform and build as examples/sony-bravia-4k-vh2 (EU) and examples/sony-kd-65x80j.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/sony-xr-65x90j/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/sony-xr-65x90j/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx (pass it to restore.sh; build-and-install.sh finds it
#   and disables it). Live TV / input app: com.sony.dtv.tvx (set it as live_tv_package and hide it; Inputs
#   lists HDMI 1-4, HDMI 3 as "eARC/ARC", AV and Live TV, and switching works).
# Keep (TV needs them): com.sony.dtv.tvx, tvinput.* (external, tuner, atsc3tuner, hardwaremanager, provider),
# braviasync*, tvapi, sonysystemservice, sonyvendorservice (it answers the YouTube/Prime Video/Netflix
# buttons: they arrive as keycodes 196 and 191 and Sony's service picks the app, so they keep working
# without launcherx), settingsprovider, imeproxy, all com.mediatek.*, systemupdate/update.
# Kept by owner's choice: Google Assistant, AirPlay/DLNA, firmware updates, YouTube, Prime Video, Apple TV,
# Sony Media Player and USB storage, notificationcenter (Sony can post update notices there).
# Already disabled at the factory: homekit, b2b.vendorprotocol, b2b.softap, youtube.tvmusic.
# Unlike the X80J (Android 10) firmware, this build has node_20_11_1, not node_12_13_1, and no
# bugreportsender or networkapp.wifidirect.
#
# Notes from this TV:
# - Network ADB: port 5555 opened only once "Network/ADB debugging" was on in Developer options, not with
#   USB debugging alone. ro.adb.secure=1, so the "Allow" prompt appears.
# - A previously installed third-party launcher (AT4K, com.overdevs.at4k) held Home through an accessibility
#   service while launcherx stayed the system default; it was uninstalled first.
# - Home: launcherx priority 2, setupwraith's RecoveryActivity priority 1. With setupwraith disabled (batch
#   8), build-and-install.sh set Home on the first try and it survives reboots.
# - Netflix button (keycode 191, a Sony global key) remapped with app_keys 191:<package> and
#   INPUT_KEY_SERVICE=1; the real button worked. But this firmware empties enabled_accessibility_services
#   on every full reboot (not on standby), so the remap needs the service re-enabled after a restart. The
#   Input button opens Sony's own input panel and needs no service.
# - 832 MB free on /data before the launcher, enough for the install without trimming caches.
# - Applied in one evening, reboot-checked twice (Home, inputs, 42 disabled packages, Ethernet).
#   Not yet lived with for weeks; if something breaks, `pm enable <package>` and please report it.
